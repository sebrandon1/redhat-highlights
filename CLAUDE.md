# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

Short summaries (50 words or less) of significant Red Hat engineering work, organized by month.

## Structure

- `README.md` — Index linking to all highlight files
- `HIGHLIGHTS-YYYY-MM.md` — Monthly highlights
- `Q*-YYYY-review.md` — Quarterly review summaries
- `TEAM-HIGHLIGHTS-YYYY-MM.md` — Team-level highlights

## Adding Highlights

1. Append entries to the current month's `HIGHLIGHTS-YYYY-MM.md` file (create if new month)
2. If starting a new month, add a link to `README.md` (newest first)
3. Each highlight should be under 50 words
